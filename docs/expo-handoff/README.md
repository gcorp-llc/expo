# 🚀 بسته‌ تحویلی بازسازی اپلیکیشن کوتیک (Kutik Expo Handoff Package)

این پوشه شامل مستندات کامل فنی، ساختاری، رفتاری و مرجع بصری اپلیکیشن **کوتیک (Kutik)** جهت بازسازی نسخه نیتیو اندروید با **Kotlin** و **Jetpack Compose** می‌باشد.

---

## 🗂️ فهرست مستندات اصلی

1. **[01-project-overview.md](01-project-overview.md):** معماری پروژه، فناوری‌ها، وابستگی‌ها و نقطه ورود.
2. **[02-screen-inventory.md](02-screen-inventory.md):** لیست کامل ۵۳ صفحه و مسیر (Route) همراه با کدهای ردیابی.
3. **[03-navigation-and-user-flows.md](03-navigation-and-user-flows.md):** نقشه ناوبری، نمودارهای Mermaid و رفتارهای دکمه بازگشت.
4. **[04-design-system.md](04-design-system.md):** توکن‌های رنگی (Light/Dark)، تایپوگرافی Vazirmatn، فاصله‌ها، شعاع انحنا و Glassmorphism.
5. **[05-icons-and-assets.md](05-icons-and-assets.md):** جدول آیکن‌های Solar Icon Set، دارایی‌های تصویری و معادل‌های VectorDrawable.
6. **[06-components-and-interactions.md](06-components-and-interactions.md):** کامپوننت‌های UI (ModernHeader, ProductCard, ChatItem, Modals).
7. **[07-screen-states-and-validation.md](07-screen-states-and-validation.md):** حالت‌های Loading, Empty, Error و قوانین اعتبارسنجی فرم‌ها (Zod).
8. **[08-api-data-and-state.md](08-api-data-and-state.md):** مدل‌های داده، Zustand Storeها و کش محلی.
9. **[09-native-android-mapping.md](09-native-android-mapping.md):** راهنمای جامع نگاشت کدها به Kotlin و Jetpack Compose.
10. **[10-acceptance-criteria.md](10-acceptance-criteria.md):** معیارهای تست و پذیرش نسخه Native با شناسه‌های ردیابی.
11. **[11-unknowns-and-limitations.md](11-unknowns-and-limitations.md):** شفاف‌سازی برچسب‌های اعتبارسنجی و محدودیت‌ها.
