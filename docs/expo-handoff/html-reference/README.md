# HTML Visual Reference — Kutik Application (کوتیک)

این پوشه شامل نمونه مستقل و قابل اجرای وب (HTML/CSS/JS) از رابط کاربری اپلیکیشن Expo/React Native کوتیک می‌باشد.

---

## 🚀 نحوه اجرا در مرورگر

۱. فایل `index.html` را به صورت مستقیم در هر مرورگر مدرن (Chrome, Firefox, Safari, Edge) باز کنید.
۲. **بدون نیاز به نصب وابستگی (pnpm/npm) یا سرور محلی (Node.js/HTTP Server).**

---

## 📱 ویژگی‌ها و قابلیت‌های مرجع بصری

- **فریم تعاملی موبایل:** شبیه‌ساز Viewport موبایل همراه با نوار وضعیت (Status Bar) و نوار ناوبری پایینی (Bottom Navigation Bar).
- **پوسته تاریک و روشن (Dark / Light Theme):** امکان تغییر لحظه‌ای پوسته جهت بررسی رنگ‌بندی‌های تعریف‌شده.
- **تغییر حالت‌های UI:** امکان بررسی وضعیت‌های `عادی (Normal)`، `بارگذاری (Loading)` و `خالی (Empty)`.
- **لیست کامل Routeها:** نوار کناری (Sidebar) امکان جابه‌جایی سریع بین تمام ۵۳ مسیر اپلیکیشن را فراهم می‌کند.
- **پشتیبانی کامل RTL:** چیدمان راستی‌چین به همراه فونت Vazirmatn جهت نمایش دقیق متون و عناصر فارسی.
- **Modal و BottomSheet تعاملی:** امکان باز کردن کشوهای سفارشی، فیلترها و فرم‌ها.
