# 📄 صفحه ورودی اصلی (Root Entry Point)

## 📌 اطلاعات پایه
- **مسیر (Route):** `/`
- **مسیر فایل سورس Expo:** `src/app/index.tsx`
- **پیشوند شناسه عناصر (Element ID Prefix):** `ROOT`
- **وضعیت بررسی:** `SOURCE_VERIFIED`
- **لینک مرجع بصری HTML:** [html-reference/index.html](../html-reference/index.html)

---

## 🎯 هدف صفحه
هدایت خودکار کاربر به صفحه اصلی یا احراز هویت.

---

## 🧩 ساختار صفحه و المان‌های بصری
- `ROOT-REDIRECT-001: هدایت خودکار Expo Router`

## 🎨 آیکن‌ها و دارایی‌ها
