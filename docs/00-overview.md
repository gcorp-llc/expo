# مستندات معماری و نمای کلی پلتفرم کاردیانی (Cardiani)

## ۱. ساختار مونو‌ریپو (Monorepo Layout)

پروژه کاردیانی با ساختار مونو‌ریپوی مدرن بر پایه **pnpm workspaces** سازماندهی شده است:

```text
cardiani/
├── apps/
│   ├── mobile/         # اپلیکیشن موبایل (Expo SDK 58, React Native 0.88, NativeWind v5)
│   └── web/            # وب‌سایت و پنل وب (Next.js 15 App Router, React 19, Tailwind CSS)
├── packages/
│   ├── shared/         # کلاینت API مستقل، اسکیماهای Zod، اعتبارسنجی‌ها و تایپ‌های مشترک
│   └── i18n/           # واژه‌نامه و فایل‌های ترجمه دو زبانه (فارسی RTL و انگلیسی LTR)
├── docs/               # راهنماهای کامل استقرار، بیلد، CI/CD و عیب‌یابی
├── .github/workflows/  # اتوماسیون CI/CD تست، بررسی کیفیت و استقرار
├── pnpm-workspace.yaml # پیکربندی فضاهای کاری pnpm
└── app.config.ts       # تنظیمات مرکزی داینامیک Expo و شناسه‌های اپلیکیشن
```

## ۲. جریان داده و مدیریت وضعیت (Data Flow & State)

1. **مدیریت وضعیت سمت کلاینت:**
   - **Zustand (`useStore`):** برای وضعیت‌های کلی اپ (سبد خرید، اطلاعات پروفایل کاربر، تم، زبان انتخابی).
   - **React Query (`@tanstack/react-query`):** برای دریافت داده‌های سرور، کش‌کردن، مدیریت وضعیت‌های بارگذاری و همگام‌سازی پس‌زمینه.
2. **لایه پایداری داده (Storage):**
   - **MMKV (`react-native-mmkv`):** ماژول ذخیره‌سازی C++ با سرعت بالا برای بیلد نیتیو.
   - **SecureStore (`expo-secure-store`):** ذخیره رمزنگاری‌شده کلیدهای حساس توکن احراز هویت (`access_token` و `refresh_token`).
   - **فال‌بک ایمن:** در محیط وب و شبیه‌سازهای توسعه سبک، به صورت خودکار به `AsyncStorage` یا `localStorage` سوئیچ می‌کند تا کرش رخ ندهد.

## ۳. تصمیم‌های فنی و معماری

- **جداسازی UI موبایل و وب:** منطق تجاری، کلاینت HTTP و اسکیماهای اعتبارسنجی در `@cardiani/shared` مشترک هستند، اما لایه UI موبایل با NativeWind و وب با استایل‌های بومی Tailwind توسعه داده شده است تا بهترین عملکرد و هماهنگی را با الگوهای طراحی هر پلتفرم داشته باشد.
- **ایمنی متغیرهای محیطی:** هیچ کلید محرمانه‌ای (Secret) نباید در کلاینت یا متغیرهای با پیشوند `EXPO_PUBLIC_` قرار گیرد. متغیرهای حساس سرور تنها در محیط‌های ایزوله یا EAS Secrets قرار می‌گیرند.
